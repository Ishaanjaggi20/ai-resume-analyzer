# AI-Powered Resume Analyzer

A full-stack web application that analyzes PDF resumes and evaluates them against industry-relevant technical skills.

## Features

* Upload PDF resumes
* Extract text using PyMuPDF
* ATS-style keyword matching
* Resume scoring
* Skill gap analysis
* Responsive React frontend
* FastAPI backend

## Tech Stack

* React.js
* FastAPI
* Python
* PyMuPDF
* REST APIs
* Netlify
* Render
